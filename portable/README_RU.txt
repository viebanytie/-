MOODLE ДЛЯ WINDOWS 10 x64 — ПОЛНЫЙ ПЕРЕНОСНОЙ КОМПЛЕКТ

1. Нажмите «Извлечь всё» у ZIP-архива. Распакуйте, например, в C:\Moodle.
2. В извлечённой папке откройте Start-Moodle.cmd двойным щелчком.
3. При первом запуске подождите несколько минут: программа сама подготовит
   локальную базу и загрузит готовый курс. Интернет для этого не нужен.
4. Откроются браузер и LOGIN.txt с вашими локальными логинами и паролями.
   Адрес: http://127.0.0.1:8088. Логины: admin и student.
5. Оставьте окно запуска открытым во время работы. Для остановки используйте
   Stop-Moodle.cmd. Курс и выполненные работы сохраняются.

Ничего отдельно скачивать или устанавливать не требуется: PHP, MariaDB,
Moodle и необходимые библиотеки уже включены. Права администратора не нужны.
Работает в 64-битной Windows 10/11. На диске нужно около 1,5 ГБ свободного места.
Открывайте запуск после полного извлечения архива, не внутри ZIP.

Курс «Цифровая безопасность: защити себя и свои данные»:
— введение и цели обучения;
— пароли и многофакторная защита;
— фишинг и проверка ссылок;
— персональные данные, устройства и резервные копии;
— итоговый тест: 10 вопросов, 15 минут, 2 попытки, порог 70%;
— практическое задание с критериями оценки.

Вход admin позволяет редактировать курс и оценивать работы.
Вход student позволяет учиться, проходить тест и сдавать практику.
Каждая копия создаёт свои случайные пароли в LOGIN.txt при первом запуске.
Резервная копия курса без пользователей: Digital_safety_course.mbz.

Интерфейс Moodle и учебные материалы — на русском.
Русский языковой пакет уже включён; интернет при запуске не нужен.
Сервер слушает только этот компьютер (127.0.0.1), порты 8088 и 3308.

Если запуск остановился: прочитайте сообщение в окне и файлы runtime\logs.
Если занят порт 8088/3308, закройте программу, которая использует его.
Если прошлый запуск был прерван, запустите Stop-Moodle.cmd, затем Start-Moodle.cmd.
Для переноса всей системы остановите её и скопируйте всю папку, включая runtime.

Основа: официальный Moodle Windows 4.5.15, PHP 8.2.4, MariaDB 10.4.28.
Источник и SHA-256 исходного архива указаны в SOURCE.json.
Лицензия Moodle: server\moodle\COPYING.txt (GPLv3).
Лицензии PHP и MariaDB находятся в server\php и server\mysql.
Настоящий комплект предназначен для выполнения локального учебного задания.
