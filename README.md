## 1. Игровой квест

**[Играть в конструкторе Joyteka](https://joyteka.com/101145854)** · номер игры `101145854`.

Профессиональный учебный кейс ML-017: пять этапов расследования утечки данных вымышленной компании. Нужно сопоставить письмо, журналы, экспорт и запись DLP, выбрать меры реагирования и отделить факты от предположений. В Joyteka используются пять вопросов с вводом ответа и итоговое заключение; покупка платного тарифа для прохождения не нужна.

Архив включает автономную браузерную игру, досье PDF, карточки и руководство преподавателя. Для локальной игры откройте **Start-Quest.cmd** или **index.html**. Интернет и дополнительные программы не нужны; результаты и прогресс сохраняются в браузере. По завершении можно скачать отчёт.

## 2. Локальный Moodle

Полный переносной комплект включает официальный Moodle 4.5.15, PHP, MariaDB, необходимые DLL, русский языковой пакет и резервную копию подготовленного курса **«Цифровая безопасность: защити себя и свои данные»**. Docker не требуется.

1. Извлеките архив в отдельную папку, например `C:\Moodle`.
2. Запустите **Start-Moodle.cmd**. При первом запуске программа сама подготовит базу и загрузит курс; подождите несколько минут.
3. Откроется `http://127.0.0.1:8088`. Локальные логины и случайные пароли будут в **LOGIN.txt**.
4. Оставляйте окно запуска открытым. Для завершения работы используйте **Stop-Moodle.cmd**.

В курсе есть введение, три темы, итоговый тест из 10 вопросов и практика с критериями оценки. Учётная запись `admin` позволяет преподавать и редактировать; `student` — проходить обучение. Данные сохраняются в папке комплекта. Сервер доступен только на самом компьютере.

Требуется Windows x64, браузер и около 1,5 ГБ свободного места. Интернет для первого запуска не нужен. Отдельная резервная копия курса: [Digital_safety_course.mbz](https://github.com/viebanytie/-/releases/download/education-portable-20261015/Digital_safety_course.mbz).

Сборка и проверка на Windows описаны в [workflow](.github/workflows/portable-windows.yml); источник и контрольная сумма официального пакета записаны внутри ZIP в SOURCE.json. Проверки включают создание базы, восстановление курса, вход преподавателя и студента, уроки, тест, практику, остановку и запуск через CMD. Отдельно проверяется автономная игра через file:// в Windows Edge и опубликованные задания Joyteka.

Ветка `education/joyteka-moodle-20261015` содержит только эти учебные материалы. Основной проект и его ветка не изменены.
