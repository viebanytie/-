# Smart Order RC20

Архив: **SmartOrder_RC20.zip** (3.18.1-rc20).

Внутри исходники и Windows-скрипты сборки. Запуск сборки: BUILD_RC20.cmd. Используйте вашу прежнюю папку resources с GIF/ICO. Результат установки: release.

Исправлены тема профиля, меню цехов, фон и документы «О приложении», подписи и единая «ФАКТ Оплата». Расширена аналитика по периодам, работам, подразделениям, сотрудникам и сменам; добавлены Min/Max, численность и интерактивная 3D-призма.

Методика и расположение таблиц: README_RC20_RU.txt внутри архива. ФАКТ часы требуют выбранной единицы работы; кг берутся из ФИКС Итогового веса строк.

163 теста; настоящий запуск на временных данных шести цехов и Excel с шестью диаграммами. Windows/SMB/UAC требуют проверки на вашей установке. Рабочие базы в архив не включены.
