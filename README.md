# Smart Order RC19

Архив исходников и скриптов Windows-сборки: **SmartOrder_RC19.zip**.

Для сборки EXE нужны Windows, Python 3.12 и оригинальные ресурсы GIF/ICO. Инструкция: README_RC19_RU.txt внутри ZIP.

Регрессия: 153 теста; проверен полный запуск на временных данных шести цехов. Windows/SMB/UAC требуют проверки на вашей установке.

Рабочие базы и пароли пользователей в архив не включены.
