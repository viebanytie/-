Smart Order 1.0

Архив исходников и средств сборки для Windows: **SmartOrder_1.0.zip**.
Пять параллельных пользователей, фоновые чтение и аналитика, обновления
списков, отдельные файлы версий нарядов и открытие .sorder в редакторе.
Поиск внутри фильтров, темы, заголовок окна, пустые обновляемые новости.

Сборка: перенесите прежнюю папку resources и запустите BUILD.cmd.
Результат: release/SmartOrderApp/SmartOrder.exe. На каждом ПК
Install_and_Start_SmartOrder.cmd создаёт ярлык и ассоциацию .sorder.
Перед заменой установки сохраните рабочие базы и данные.

В архиве README_RU.txt, docs/ANALYTICS_RU.txt и docs/TEST_REPORT_RU.txt.
176 тестов прошли. Пять процессов сохранили 50 нарядов с уникальными
номерами и 50 файлов. При конфликте одной версии одна правка сохранена,
четыре отклонены как устаревшие. Сквозной запуск и Excel прошли.
Проверки выполнены в Linux; Windows/SMB, UAC, системные кнопки и Windows
сборку необходимо проверить в вашей среде. Готового Windows EXE в ZIP нет.
Оригинальные GIF/ICO не входили в загруженный исходный архив.

Ветка main не изменена. Контрольная сумма находится в соседнем .sha256.
