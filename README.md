Smart Order 1.0 — исправление заголовка, столбцов и первого показа редактора

Архив **SmartOrder_1.0_FIX.zip** содержит исходники и сборку для Windows.
Три кнопки управления рисуются непосредственно в видимой полосе заголовка
со стандартными символами; подложка и цвет соответствуют выбранной теме.
Ширина столбцов нарядов рассчитана по заголовкам и содержимому, свободное
место распределяется между мастером и подразделением.
Кнопка Excel создаётся сразу внутри редактора, без отдельного белого окна.
Размер и тема редактора устанавливаются до его первого показа.

185 тестов прошли, включая обе темы, масштаб 100–200%, операции трёх кнопок,
единственный показ редактора и совместную работу пяти процессов.
Сквозной запуск, аналитика и Excel прошли; примеры находятся в demo.
Win32-маршрутизация нажатий проверена с моделью API; реальная Windows/SMB,
DPI, UAC и Windows-сборка в облачной Linux-среде не исполнялись.

Сборка: перенесите прежнюю папку resources, запустите BUILD.cmd.
Результат: release/SmartOrderApp/SmartOrder.exe.
Готового Windows EXE в ZIP нет. Перед обновлением сохраните рабочие базы.
Версия программы остаётся 1.0. Ветка main не изменена.
Инструкция и подробный отчёт проверки находятся внутри ZIP.
