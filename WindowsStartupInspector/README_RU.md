# Windows Startup Inspector 1.1.0

Простая текстовая программа на Python для Windows 10/11. При запуске открываются два отдельных окна: автозапуск программ и все службы, включая остановленные, отключённые службы и драйверы. Списки можно искать, сортировать по заголовкам, фильтровать и экспортировать в CSV для Excel. У каждой записи есть подробности и поле собственного комментария.

## Запуск и сборка через CMD

1. Установите **Python 3.12 x64** с python.org. Оставьте компоненты **Tcl/Tk** и **Python Launcher** включёнными.
2. Распакуйте весь ZIP в обычную папку, например `C:\Tools\WindowsStartupInspector`. Не запускайте CMD внутри открытого ZIP.
3. Откройте `START.cmd` для запуска исходников. Сторонние Python-библиотеки для работы программы не нужны.
4. Для получения одного EXE откройте `BUILD.cmd`, либо выполните в CMD:

   ```cmd
   cd /d C:\Tools\WindowsStartupInspector
   BUILD.cmd -Clean
   ```

   Сборщик создаёт `.venv-build`, устанавливает фиксированные версии зависимостей из `requirements-build.txt`, запускает тесты и собирает `dist\WindowsStartupInspector.exe`. Для первой сборки нужен Интернет: `pypi.org` и `files.pythonhosted.org`. Проверка TLS не отключается. CMD сохраняет код ошибки сборки.

5. Готовый EXE можно перенести на Windows-компьютер без Python. Windows PowerShell 5.1, WMI/CIM и планировщик заданий должны быть доступны: это штатные компоненты Windows 10. EXE собирается на Windows, не на Linux.

Для управления системными записями и чтения максимально доступных данных запустите `START.cmd` или EXE **от имени администратора**. Кнопка **«Права администратора»** запускает отдельную копию с запросом UAC: сохраните заметки и закройте прежнюю копию. Без повышения прав ошибки доступа отображаются; защита Windows не обходится. Корпоративная политика может запрещать PowerShell.

## Управление и копирование

Выберите запись и используйте кнопки или ПКМ. Каждое изменение требует подтверждения.

- **Отключить / Включить обратно:** Run/RunOnce/Policies\Explorer\Run переносится с сохранением типа значения в подветку `WindowsStartupInspector_Disabled` и обратно. Файл Startup переносится в соседнюю папку `WindowsStartupInspector_Disabled_Startup` за пределами Startup; при включении возвращается. Отключённые записи остаются видимыми. Существующие копии и файлы не перезаписываются, конфликты отображаются.
- **Задания:** выключается или включается конкретное задание по точному имени и пути. Условия, триггеры и уже работающие действия не изменяются.
- **Службы/драйверы:** `sc.exe` устанавливает тип «Отключена». Прежний тип, включая отложенный автозапуск, сохраняется в `%LOCALAPPDATA%\WindowsStartupInspector\service-backups`. Обратное включение восстанавливает его; без копии устанавливает **ручной** запуск. Уже разрешённый тип повторная команда включения не меняет. Восстанавливайте под тем же Windows-профилем, который создал копию.
- **Остановить сейчас / Запустить сейчас:** отдельные команды службам, без изменения типа запуска. Отключение типа запуска само по себе **не останавливает работающую службу**. Принудительная остановка зависимых служб не выполняется. После операций список перечитывается; промежуточное состояние можно перепроверить F5.
- Для драйверов и выбранных системных/защитных служб отключение или остановка требуют ввода системного имени. Winlogon/Shell/Userinit и BootExecute остаются **только для просмотра**, чтобы кнопкой не удалять параметры входа и загрузки. Windows может отказать в изменении защищённой службы.

ПКМ по строке копирует всю запись, название, команду/путь, описание или подробности. ПКМ в текстовом поле копирует выделенный или весь текст. В окне диагностики можно копировать находку и весь отчёт.

## Проверка майнера

Кнопка **«Проверка майнера»** открывает отдельное окно и запускает локальный анализ доступных данных:

- Процессы, пути, команды, известные названия майнеров, Stratum, характерные аргументы и домены пулов. PowerShell EncodedCommand может декодироваться **без выполнения кода**.
- CPU за 5 секунд, нормированный на весь компьютер; доступные счётчики WDDM GPU по PID.
- Активные TCP-подключения с PID и локальный кэш DNS. Номер порта или DNS-запись сами по себе не доказывают наличие майнера.
- Автозапуск, службы/драйверы; дополнительно все доступные действия заданий, включая периодические, WMI CommandLine/ActiveScript Event Consumers и IFEO/SilentProcessExit.
- Статус, возраст сигнатур, активные угрозы, история и доступные исключения Microsoft Defender.
- Authenticode и SHA-256 до 100 файлов-кандидатов: процессы с характерными командами, высокой нагрузкой или из пользовательских папок, подозрительные команды закрепления. Хеши **не сверяются с внешней базой**, а подпись не доказывает безопасность.

Отчёт различает контекст, подозрительные признаки, активную майнер-угрозу по данным Defender, историю обнаружений, недоступные методы и отмену. Имя, нагрузка, папка AppData или отсутствие подписи по отдельности не доказывают заражение; легальный майнер тоже может быть отмечен. Отсутствие совпадений не гарантирует отсутствие майнера. Отчёт можно скопировать или сохранить в TXT.

Отдельные кнопки запускают **быструю** или **полную** проверку Defender. Проверяется подпись штатного MpCmdRun.exe; завершение сверяется с кодом и текущими временными отметками сканирования. Код 0 может означать и успешно обработанную угрозу. Defender может обработать/поместить угрозы в карантин по настройкам Windows — перед запуском будет подтверждение. Полная проверка может длиться часами; закрытие окна программы не отменяет проверку Windows.

**«Автономная: инструкция»** объясняет запуск Microsoft Defender Offline через Windows Security. Метод требует перезагрузки, самой программой не запускается и выполненным не считается. Программа не выполняет все известные методы, анализ памяти/ядра, сверку с внешней базой или профессиональный поиск rootkit. Возможны спящие и переименованные майнеры, внедрение в процессы и новые варианты.

Сбор данных и эвристики не завершают процессы и не удаляют файлы. Управление и Defender выполняют только отдельно выбранные действия. Данные и хеши этой программой в сеть не отправляются; штатный Defender использует собственные настройки облачной защиты Windows.

## Что отображается

Автозапуск:

- Run, RunOnce и Policies\Explorer\Run в 32- и 64-битном реестре: компьютер и **уже загруженные** пользовательские ветки HKU.
- Доступные папки Startup всех обнаруженных профилей, общая папка Startup и перенаправленные папки загруженных профилей. Для ярлыков показываются цель, аргументы и рабочая папка.
- Отметки StartupApproved: отключённые записи остаются видимыми. «Нет отметки отключения» означает отсутствие известного флага, а не доказанный факт запуска процесса.
- Задания планировщика с триггером загрузки или входа, включая отключённые задания. Другие условия задания могут препятствовать запуску.
- Shell/Userinit Winlogon и BootExecute.

Это обзор основных источников автозапуска, а не полный аналог Sysinternals Autoruns. Незагруженные пользовательские файлы NTUSER.DAT не монтируются; расширения оболочки, AppInit_DLLs, WMI event consumers и все остальные специальные механизмы здесь не перечисляются. Список — снимок настроек, а не журнал уже запущенных процессов. Реально работающие службы видны по состоянию «Работает».

Службы:

- **Все записи, которые Windows возвращает через Win32_Service и Win32_SystemDriver**, без фильтра по состоянию или типу запуска. По умолчанию включены драйверы и отключённые службы.
- Отображаемое и системное имя, описание Windows, состояние, тип запуска, учётная запись, команда/путь, тип службы и код выхода.
- Отложенный автоматический запуск, зарегистрированные зависимости и число триггеров из реестра, если доступны.
- При отсутствии системного описания используется описание файла; если нет и его, это явно указано. Универсальные советы о безопасности отключения конкретных служб программа не выдумывает.

Кнопка **«Ошибки / полнота списка»** показывает источники и ошибки чтения. При недоступности WMI, планировщика, реестра или чужих папок нельзя считать снимок полным. Даже запущенная служба с ручным типом запуска может работать благодаря триггеру или запросу другой программы. Тип «Автоматически» сам по себе не доказывает, что служба успешно запустилась.

## Комментарии и экспорт

Выберите запись, введите заметку и нажмите **«Сохранить комментарий»**. Заметки находятся в `%LOCALAPPDATA%\WindowsStartupInspector\comments.json` и восстанавливаются при следующих запусках. Пустой комментарий удаляет заметку. Изменения в поле нужно сохранить до выбора другой записи. Повреждённый файл заметок не перезаписывается.

CSV содержит **текущий отфильтрованный список** вместе с описаниями, путями, подробностями и вашими сохранёнными заметками. Кодировка UTF-8 с BOM, разделитель `;`. Поиск учитывает также путь, подробности и сохранённые комментарии.

`F5` обновляет текущее окно, `Ctrl+F` ставит курсор в поиск. Закрытие окна служб скрывает его: используйте «Открыть другое окно». Закрытие основного окна автозапуска или кнопка «Выход» закрывает всю программу.

## Проверка и диагностика

```cmd
py -3.12 -m unittest discover -s tests -v
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests\check_powershell.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests\check_controls.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests\check_security.ps1
py -3.12 startup_inspector.py --dump startup > startup.json
py -3.12 startup_inspector.py --dump services > services.json
py -3.12 startup_inspector.py --demo
```

`--demo` показывает **вымышленные** записи и помечает окна. Управление изменяет только записи на экране; F5 возвращает исходные демонстрационные данные. Проверка майнера использует придуманный пример, Defender и UAC не запускаются. Это проверка интерфейса, а не инвентаризация компьютера. JSON-команды завершаются с ненулевым кодом при сбое чтения; частичная инвентаризация содержит `warnings`.

Для разработки на Linux: Python 3.12 с Tk, `python3 -m unittest discover -s tests -v`; просмотр интерфейса — `python3 startup_inspector.py --demo`. Сборка и реальная инвентаризация Windows требуют Windows 10/11. Дополнительная проверка GUI: `python3 tests/gui_smoke.py` при доступном дисплее.

Локальные адаптеры: `inspect_windows.ps1`, `manage_windows.ps1`, `security_probe.ps1`. ZIP содержит исходники, тесты и сборщик; готового Windows EXE в исходном архиве нет. Ранее опубликованный ZIP версии 1.0.0 остаётся отдельной версией.
