# Проверка версии 1.0.0

Проверки выполнены 9 октября 2026 года в Linux-среде с Python 3.12.14 и Tk 9.0.

- 18 тестов `unittest`: пройдены. Проверены протокол JSON, русские символы, частичные ошибки, тайм-аут и отказ процесса, сохранение/защита заметок, CSV, поиск, остановленные и отключённые службы, драйверы и разные значения фильтров.
- Функциональная проверка двух реальных Tk-окон на виртуальном дисплее: пройдена. Проверены фоновая загрузка демонстрационных данных, подробности, поиск, сортировка, сохранение комментария, экспорт, фильтр драйверов, обновление и повторное открытие окна служб.
- PowerShell 7.4.6: синтаксис сборщика и коллектора, отметки StartupApproved, ошибки доступа и преобразование тестовых записей служб/драйверов проверены. Использованы тестовые данные; реальные службы Windows не читались. Архив PowerShell получен из официального GitHub-релиза и проверен по опубликованному SHA-256.
- PyInstaller 6.16.0: Linux-упаковка проверена, включая встроенные JSON/PowerShell-ресурсы и запуск демонстрационного GUI. Linux-бинарник в исходный ZIP не включён.
- Исходный ZIP повторно распакован; тесты и проверка интерфейса запущены из распакованной папки. Архив проверен на целостность и отсутствие временных данных.

**Не выполнено в этой среде:** сборка Windows EXE, запуск Windows PowerShell 5.1, чтение настоящего реестра/планировщика/служб Windows 10, проверки прав обычного пользователя и администратора. Для этого нужны Windows 10/11 и команды из README_RU.md. Эти проверки не считаются пройденными на основании демонстрационного режима или тестовых данных.
